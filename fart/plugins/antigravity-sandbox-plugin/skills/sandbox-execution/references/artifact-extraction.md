# Artifact Extraction & Rich Output Reference Guide

This reference explains how visualizations, tabular datasets, and file outputs generated inside the Antigravity sandbox are automatically captured, serialized, and returned to autonomous agents.

---

## 1. Artifact Model & Classification

The execution engine inspects the sandbox environment after each execution turn and extracts structured artifacts adhering to the `Artifact` schema:

```json
{
  "name": "figure_1.png",
  "mime_type": "image/png",
  "artifact_type": "image/png",
  "data_base64": "iVBORw0KGgoAAAANSUhEUgAA...",
  "metadata": {
    "title": "Loss Curve",
    "width": 800,
    "height": 400
  }
}
```

### Supported Artifact Types:
1. **Visualizations / Plots**: PNG, SVG, PDF generated by `matplotlib`, `seaborn`, or `plotly`.
2. **Tabular Datasets**: CSV, JSON formatted tables from `pandas`, `polars`, or custom Python dicts.
3. **Exported Files**: Any files written to the designated `/tmp/artifacts/` directory.

---

## 2. Capturing Matplotlib & Seaborn Visualizations

The execution engine automatically hooks `matplotlib.pyplot.show()` to intercept rendering buffers.

### Recommended Usage:
```python
import matplotlib.pyplot as plt

# Generate plot
plt.figure(figsize=(8, 4))
plt.plot([1, 2, 3, 4], [10, 20, 25, 30], marker='o', color='#1f77b4', label='Accuracy')
plt.title('Model Convergence')
plt.xlabel('Epoch')
plt.ylabel('Score (%)')
plt.legend()
plt.grid(True)

# Calling show() automatically extracts the figure as a base64 PNG artifact
plt.show()
```

### Multiple Plots in a Single Turn:
You can render multiple figures sequentially; each `plt.show()` call is captured as a distinct artifact in the results list:
```python
# Figure 1: Distribution
plt.figure()
plt.hist([1, 2, 2, 3, 3, 3, 4, 4, 5], bins=5, color='orange')
plt.title('Distribution')
plt.show()

# Figure 2: Boxplot
plt.figure()
plt.boxplot([10, 12, 14, 15, 18, 19, 22])
plt.title('Outlier Analysis')
plt.show()
```

## 3. Tabular Dataset Extraction

When processing structured datasets with `pandas` or `polars`, agents can output summary tables directly into the artifact pipeline:

```python
import pandas as pd

df = pd.DataFrame({
    'category': ['Alpha', 'Beta', 'Gamma', 'Delta'],
    'revenue': [152000, 234000, 89000, 412000],
    'margin': [0.18, 0.24, 0.12, 0.31]
})

# Save to artifacts directory for automatic indexing and extraction
df.to_csv('/tmp/artifacts/financial_summary.csv', index=False)
print("Saved financial_summary.csv to artifacts")
```

## 4. File-Based Artifact Harvesting (`/tmp/artifacts`)

Any files written to `/tmp/artifacts/` (or relative `./artifacts/` in local fallback) are harvested at the end of the execution block.

### Example: Generating and Exporting Reports
```python
import json

report = {
    "timestamp": "2026-08-29T03:00:00Z",
    "metrics": {
        "precision": 0.942,
        "recall": 0.918,
        "f1_score": 0.930
    },
    "status": "HEALTHY"
}

with open('/tmp/artifacts/eval_report.json', 'w') as f:
    json.dump(report, f, indent=2)

print("Evaluation report saved.")
```

## 5. Artifact Delivery to User & UI Agents

Artifacts returned in the tool response can be displayed directly in agent UIs:
- **Base64 Images**: Embedded as Markdown data URIs `![Chart](data:image/png;base64,...)` or rendered natively by UI clients.
- **CSV / Data Tables**: Rendered as interactive Markdown tables or downloadable files.
