# Hur man använder Json-rules-engine

## Förberedelser
* Du behöver ha Node.js installerat
* Börja med att köra "npm install" för att installera json-rules-engine
* Kör önskad exempelfil med node, ex i konsolen, kör "node exempel_1"

## Förklaring av exempelfiler

### exempel_1.js
Enklast möjliga exempel. Innehåller bara en regel.

### exempel_2.js
Flera regler från en separat regelfil.

### exempel_3.js
Mappad app-specifik input. Exemplet visar också hur "on success" kan användas.

### exempel_4.js
App-specifik action/output

### exempel_5.js
Beräkning i regelfil. Hämta belopp och exekvera beräkning.

### exempel_6.js
Blandade alternativa lösningar
